# Project and chat rule

Default: one chat = one project or collection.

- Same collection, new concept, review, revision, engineering, BOM or packaging: stay in the same chat so context is preserved.
- New unrelated project/collection: recommend a new chat and reuse the guided brief template.
- Page refresh does not create a new project.
- If the user insists on starting a second project in the same chat, explicitly label the new project and avoid mixing decisions between projects.
