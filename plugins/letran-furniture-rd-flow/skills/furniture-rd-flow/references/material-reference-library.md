# Company mechanical material reference

Source: uploaded workbook `09_BC Vật tư Cơ khí.xlsx`, sheet `Danh mục Vật tư`, snapshot prepared 2026-09-29.

This is a **reference snapshot for Stage 04+ only**. It contains 611 rows marked as steel (`LÀ SẮT = TRUE`). It indicates materials that appear in the company's working catalog/history; it does **not** prove current inventory, price, supplier availability, suitability for a new load case, or factory approval.

## Critical usage rule

Do not read or use this library during Stages 01-03 concept generation/revision. Concept generation must remain driven by brief, market, Design DNA, function, aesthetics and plausible manufacturability.

At Stage 04, first determine the engineering need from the approved concept, then use this library to look for compatible existing materials. Existing catalog items are preferred only when they preserve the approved design intent and technical requirement. Missing matches are allowed and must be flagged `AI Proposal - vật tư mới / chưa có trong danh mục`.
