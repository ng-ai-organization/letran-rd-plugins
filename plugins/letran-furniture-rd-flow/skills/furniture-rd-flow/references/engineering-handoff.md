# Controlled engineering handoff

Use this reference when preparing technical handoff content from Stages 04-07.

Build assembly and part breakdowns with unique controlled Part No., drawing/revision references and status. For seating, model seat frame, left/right arm-leg modules, backrest, supports, final weld assembly, finish, weaving, cushion and hardware as distinct groups where appropriate. Render callout numbers are never the controlled parts list.

For steel, record section/profile, wall thickness, cut length or raw size, bends, weld/jig sequence, coating requirement and status when known. For weaving, record profile/pattern/path/anchor/termination/consumption/labor only when controlled geometry and process information support it; otherwise keep fields TBD.

BOM contains material/part/qty/size/process/status. It does not calculate product cost unless a future workflow explicitly adds verified costing data.

Packaging/loading must distinguish proposed versus verified packed LxWxH, gross weight, pcs/carton, orientation, protection, KD/stack plan and container assumptions.

2D review can use PDF; exchange can use DXF/DWG in mm when controlled geometry exists. OBJ/SCAD can support rough communication; STEP/native CAD and production drawings require adequate geometry and engineer verification. Never state that an engineering file is ready when the current environment cannot actually create it.
