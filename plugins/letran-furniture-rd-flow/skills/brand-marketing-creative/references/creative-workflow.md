# Creative workflow - four flexible stages

## Principle

Use the smallest path that completes the user's goal. The four stages are a mental model, not a required wizard.

## 1. Brief

Extract only useful inputs:
- brand / project / product;
- objective;
- audience / market;
- channel / format;
- desired style;
- available assets;
- language;
- deadline or constraints when supplied.

If important fields are missing, propose defaults. Ask at most 1-3 grouped questions when the missing answer would materially change the creative output.

For a broad new campaign, a compact brief can be shown:

**Brief nhanh**
- Thương hiệu / dự án:
- Mục tiêu:
- Sản phẩm / dịch vụ:
- Đối tượng / thị trường:
- Kênh sử dụng:
- Phong cách mong muốn:
- Có cần bám trend hiện tại không:
- Hình ảnh / tài sản có sẵn:

The user may answer in free text; never force form re-entry.

## 2. Ý tưởng & Trend

For a broad campaign, propose 2-3 genuinely different Creative Directions. Each should include:
- direction name;
- Big Idea;
- audience insight or communication angle;
- visual language;
- key message / headline territory;
- suitable channels;
- why it fits the brief;
- any trend signal used and whether it is durable or short-lived.

Do not do trend research when it adds no value. Do research when freshness is explicitly requested or materially important.

## 3. Sản xuất Creative

Produce only the assets requested, or a sensible starter set for a full campaign.

Possible outputs:
- poster / key visual;
- social visual directions;
- banner / digital display;
- catalog or brochure direction;
- campaign imagery and image edits;
- 2D compositions;
- conceptual 3D marketing scenes;
- headlines, taglines, body copy, captions, CTA;
- content series or lightweight content calendar.

For a new broad campaign, default to a `Creative Starter Pack` rather than dozens of assets:
- 2-3 Creative Directions;
- 2-3 poster/KV concepts;
- matching headline/key-message territories;
- one recommended direction to develop further only if the user asks for evaluation; otherwise present differences neutrally;
- relevant next actions.

## 4. Review & Xuất

Apply revisions without losing accepted decisions. When a deliverable is finalized, state what is final and what remains draft.

Possible handoff items:
- final copy;
- visual assets created in the current environment;
- art-direction sheet;
- campaign message system;
- asset list / channel adaptations;
- reusable prompts or production notes;
- source/reference links for researched trends.

Never claim an editable PSD/AI/3D production file exists unless the environment actually creates it.
