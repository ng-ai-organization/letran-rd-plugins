# Creative workflow - four flexible stages

## Principle

Use the smallest path that completes the user's goal. The four stages are a mental model, not a wizard.

## 1. Brief

Extract only useful inputs: brand/project/product, objective, audience/market, channel/format, desired style, available assets, language and constraints.

If important fields are missing, propose defaults. Ask at most 1-3 grouped questions only when the answers materially change the creative result.

## 2. Ý tưởng & Trend

For broad creative work, produce 2-3 genuinely different directions. Use [idea-generation.md](idea-generation.md).

If current trend research is requested or useful, research first, then synthesize using [trend-research.md](trend-research.md). Do not show a long research report before ideas unless the user explicitly asks for one.

Default output order:
1. `Creative Opportunity 01`
2. `Creative Opportunity 02`
3. `Creative Opportunity 03`
4. a compact evidence note showing which current signals informed each direction.

Every direction must include a Big Idea and a concrete hero poster/KV execution.

## 3. Sản xuất Creative

Produce only requested assets, or a sensible starter set.

Possible outputs:
- poster / key visual;
- social visual directions;
- banner / digital display;
- catalog/brochure direction;
- image edits;
- 2D composition;
- conceptual 3D marketing scenes;
- headlines, taglines, body copy, captions, CTA;
- content series.

When image tools are available and the user wants a visual, create the visual instead of stopping at a prompt description.

## 4. Review & Xuất

Apply revisions without losing accepted decisions. When a deliverable is finalized, distinguish final assets from directions/specifications.

Never claim native editable production files exist unless they were actually created.
